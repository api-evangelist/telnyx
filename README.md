Telnyx is a carrier-owned, private-IP cloud communications and AI infrastructure platform. Its REST API (api.telnyx.com/v2, ~1,400 operations) covers programmable voice and SIP trunking, SMS/MMS/RCS/WhatsApp messaging, email, fax, phone numbers and porting, IoT SIM and private wireless, networking, storage, AI inference, embeddings, voice AI assistants and agent memory, plus a hosted MCP server, OAuth 2.0 and x402 pay-per-call access for agents.

**Areas:** Communications · CPaaS · Voice · SMS · IoT · Telecommunications · Messaging · Artificial Intelligence · MCP · Voice AI · Phone Numbers · Inference

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).
