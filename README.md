# Telnyx (telnyx)

Telnyx is a private-IP cloud communications platform offering voice (SIP / programmable), SMS, MMS, fax, number management, IoT SIM, AI inference, and authentication APIs.

**APIs.json:** [https://raw.githubusercontent.com/api-evangelist/telnyx/refs/heads/main/apis.yml](https://raw.githubusercontent.com/api-evangelist/telnyx/refs/heads/main/apis.yml)
